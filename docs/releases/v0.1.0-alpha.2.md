UI and macOS fixes for the first tester Alpha.

### Changed

- Fixed Settings expanding horizontally and hiding controls. Long explanations wrap, and controls reflow in narrower windows.
- Simplified Agenda: events come first, date filters open on demand, and reminder preferences live in Settings with a direct shortcut from Agenda.
- Moved secondary explanations in Downloads, Courses, offline files, Inbox and Settings behind expandable help.
- Downloads now show persistent in-app progress, success or failure feedback in the toolbar while Moodle is open. Click it to open Downloads, or dismiss it. Completed rows have a success checkmark.
- Clarified storage under `~/Moodle`, by organisation and course, with Show in Finder for exact locations and an explanation of the internal folder-name suffixes. Existing files are not moved.
- Changed the default models to `DeepSeek-V4-Flash-0731` for Albert and `mistral-large-4` for Mistral Large 4. Explicitly saved model choices are preserved.
- Added a native Icon Composer asset for macOS 26+ to avoid the grey legacy-icon surround; older macOS retains the existing icon fallback.
- Remember the main window's size, position and maximized state across launches. Restore bounds are constrained to an available display. Account, popup and reader windows are not persisted.

### Verified

101 frontend and 97 Rust tests pass, along with lint/format/build, Clippy and IPC guards. WebKit checks cover the main shell views, FR/EN, narrow layouts and dark/high-contrast states. A separate native process saved and restored a 1040×680 window. Universal architectures, package signatures and DMG checksums are verified before upload.

### Install

Quit MoodBuro, download the universal DMG and checksum below, then replace the app in Applications. It supports Intel and Apple Silicon. The app remains ad-hoc signed and not notarized; see the [installation guide](https://github.com/kilianvivien/MoodBuro/blob/v0.1.0-alpha.2/docs/alpha-install.md) for first-launch Gatekeeper instructions.

This is an early tester prerelease. Live provider/Moodle, clean-machine, Intel execution and full native accessibility/platform qualification remain open. There is no automatic updater.
