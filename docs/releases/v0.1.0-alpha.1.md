First tester Alpha of MoodBuro, a bilingual macOS desktop home for Moodle.

### Download and installation

Download **MoodBuro_0.1.0-alpha.1_universal.dmg** below. This universal release includes Apple Silicon and Intel binaries; the configured minimum is macOS 12. Verify the download against **SHA256SUMS.txt**, open the DMG and drag MoodBuro into Applications.

The app is **ad-hoc signed, not Developer ID signed or notarized**. macOS may block first launch: attempt to open the app, then use System Settings → Privacy & Security → Open Anyway. See the [installation and upgrade guide](https://github.com/kilianvivien/MoodBuro/blob/v0.1.0-alpha.1/docs/alpha-install.md), including older macOS instructions. This private prerelease requires repository access.

### Included

- French/English macOS shell, multiple Moodle organisations, native menus, site navigation, sign-in and session restoration.
- Notification inbox, background polling, unread badge and menu-bar access.
- Course browser, pins, cached activity search and Quick Open, including an optional global shortcut.
- Downloads with course folders, native document previews and selected offline course files with manual refresh.
- Agenda, opt-in local deadline reminders and manual ICS calendar export.
- Optional Albert API/Mistral AI assistant with your own key, streamed chat, explicit Moodle context sharing, source links and confirmation before notification-read actions.

### Validation and known limits

100 frontend tests and 95 Rust tests pass. Frontend lint/format/build, Rust format/Clippy and shell-only IPC checks pass. The universal app and DMG undergo signature, architecture and disk-image verification before upload; the SHA-256 file identifies the uploaded installer.

This release makes the implemented Alpha features available for testing. Live multi-site SSO, notification delivery/clicks, native downloads and offline behavior, VoiceOver/keyboard coverage, Intel runtime and the supported macOS matrix still need qualification. The assistant has provider/Moodle fixture coverage; live Albert/Mistral credentials and real-site tools still need qualification. See [implementation status](https://github.com/kilianvivien/MoodBuro/blob/v0.1.0-alpha.1/docs/implementation-status.md) and the linked QA guides.

There is **no automatic updater**. Future alphas install manually. The ad-hoc signature may cause Keychain permission prompts again after an update. Closing the main window keeps the app running; use Quit to stop it.

Please report reproducible issues with app/OS/processor details, without credentials or private Moodle data.
