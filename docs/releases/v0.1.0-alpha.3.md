Assistant, reminders and session recovery improvements for the tester Alpha.

### Changed

- Retry rate-limited Moodle session restoration once after a conservative delay. Navigation, logout, reconnect and account removal cancel obsolete recovery attempts.
- Refined the AI assistant panel, conversation formatting and context selection, with course-aware actions and guarded opening of saved course files.
- Improved notification and reminder wording and added per-event reminder selection in Agenda.
- Refreshed the macOS menu-bar icon and clarified the tray menu.

### Verified

107 frontend and 104 Rust tests pass, along with lint, formatting, the production frontend build, workspace Clippy and shell IPC guards. Packaging verification covers both executable architectures, strict deep ad-hoc signature verification and DMG integrity; live/native qualification remains open.

### Install

Quit MoodBuro, download **MoodBuro_0.1.0-alpha.3_universal.dmg** and **SHA256SUMS.txt**, verify the checksum, then replace the app in Applications. The universal installer includes Apple Silicon and Intel binaries; the configured minimum is macOS 12.

The app is **ad-hoc signed, not Developer ID signed or notarized**. Follow the [installation guide](https://github.com/kilianvivien/MoodBuro/blob/v0.1.0-alpha.3/docs/alpha-install.md) for Gatekeeper instructions. Upgrades are manual; there is no automatic updater.

This is an early tester prerelease. Live provider/Moodle behavior, clean-machine installation, Intel execution and full native accessibility/platform qualification remain open.
