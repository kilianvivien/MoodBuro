MoodBuro’s first regular release for macOS.

### Included

- The real Moodle site in a native macOS shell, with multiple organisations, French/English UI, native menus and light/dark appearance.
- Notifications, courses, agenda, local reminders, managed downloads and selected offline course files.
- An optional Albert/Mistral AI assistant with your own API key, explicit context sharing and confirmed actions.

### New since alpha.3

- Bookmark Moodle pages with **⌘D** or the toolbar button. Edit names and choose from eight icons; five bookmarks appear in the sidebar, with additional entries in a native overflow menu. File → Edit Bookmarks… opens the full manager.
- **⌘K** opens Quick Open over the current view, keeping Moodle visible underneath.
- Long course titles wrap without overlapping header actions.
- Moodle’s temporary automatic-sign-in limit now shows an explanation and the scheduled retry time, followed by retry/failure status.
- macOS credentials share one Keychain item and one serialized startup read. Existing entries migrate safely; the first migration can still prompt for each old item. Later startup consumers share the combined item.

### Install and upgrade

Download **MoodBuro_0.1.0_universal.dmg** and **SHA256SUMS.txt**. Verify the checksum, quit MoodBuro, then drag the new app into Applications. The universal installer contains Apple Silicon and Intel binaries; the configured minimum is macOS 12.

The app remains **ad-hoc signed, not Developer ID signed or notarized**. See the [installation guide](https://github.com/kilianvivien/MoodBuro/blob/v0.1.0/docs/alpha-install.md) for Gatekeeper instructions. Upgrades are manual; there is no automatic updater. Repository access is required if the repository is private.

### Verification and scope

109 frontend and 112 Rust tests pass, alongside lint, formatting, production frontend build, workspace Clippy and shell IPC guards. WebKit fixture checks cover bookmark editing and narrow/dark/high-contrast layouts; an isolated native test verifies Quick Open sibling ordering without hiding Moodle. The universal installer’s architectures, ad-hoc signature and disk image integrity are checked before upload.

This is a regular GitHub release, not a prerelease. Live Moodle/provider behavior, clean-machine installation, Intel execution and full native accessibility/platform qualification remain open.
